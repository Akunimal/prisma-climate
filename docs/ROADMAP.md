# Roadmap

Phases with exit gates. A gate that does not pass is documented as a negative result — that is also a result. Dates are indicative for a single person; the gate, not the calendar, decides progression.

| Phase | Indicative window | Deliverable | Exit gate |
|---|---|---|---|
| **0 · Honest repo** | now | README with real status, licence, `DATA_SOURCES.md`, working ingest (Open-Meteo + GHCN + indices), notebook 01 with real figures for the region, daily forecast-archive workflow | Someone clones the repo and reproduces a figure with one command |
| **1 · Verification** | 2–4 weeks | Daily automatic ingest (GitHub Actions), SMN connector, QC + source-discrepancy report, first real metrics in `results/`, `EVALUATION_PROTOCOL.md` in force | Leaderboard of raw ensemble vs climatology vs persistence, generated by script |
| **2 · Calibration + app v0.1** | 1–2 months | EMOS / quantile mapping, FastAPI, Flutter app (web + Android) with screens 1–3 | CRPSS > 0 of calibrated vs raw ensemble; public app reachable by link |
| **3 · Subseasonal + alerts** | 2–4 months | 2–6 week horizon with ML, ENSO conditioning, screens 4–5, iOS/Windows | ML model beats the Phase 2 calibration on at least one lead time, or that is documented |
| **4 · Public good + partners** | 4–6 months | Dataset and models with DOI (Zenodo), preprint or technical report, contact with university / CONICET / INTA | At least one institutional partner interested (requirement for grants) |

## Current status (Phase 1 in progress)

Done:

- Repo structure, Apache-2.0 licence, `CITATION.cff`, honest README.
- Source registry with licences, cadence, day conventions (`configs/sources.yaml`).
- Connectors: Open-Meteo (ERA5 + ensemble), GHCN-Daily, NOAA ONI/SAM; QC pass; Parquet storage.
- Region config for 19 stations across Argentina's climate zones with selection criteria documented.
- Daily ingest workflow with Hugging Face upload and Release fallback; status heartbeat commit.
- SMN access re-verified (open-data endpoints reachable); PAD licence + Infoleg data policy read (CC BY 2.5 AR with attribution, covers raw observational data); payloads probed; `day_convention: local_calendar` verified from `datohorario`/`observaciones`.
- SMN connector (`ingest/smn.py`): catalogue → NRO → observaciones match, daily TMAX/TMIN merged into `data/raw/smn-argentina.parquet`; source `status: active`.
- ERA5 vs GHCN discrepancy report with t2m_max bias decomposition and precip orography check; SMN leg added over the regtemp capture (19/19 stations by NRO, local-calendar joins, gaps reported, never filled).
- Verification metrics module + unit tests (`backend/src/prisma/verify/metrics.py`); leaderboard gated until archive ≥ 15 issue dates.
- Redundant archive cron slots (06:47, 12:17, 18:31 UTC) plus a same-day no-op test; schedule itself still UNPROVEN (no `event=schedule` run as of 2026-11-12 — that day was archived by a manual `workflow_dispatch` rescue).

Not started (by design): leaderboard numbers, calibration, API, Flutter app.
